# Phase 2 — HTTP, WebSocket di controllo e catalogo condiviso

> **Intent:** rendere operativa, tramite harness interno, una room browser in cui tutti i peer possono pubblicare e vedere offerte, senza alcun trasferimento automatico o manuale ancora disponibile.
> **Shippable alone?** no — le route funzionano nei test ma il comando pubblico che crea e mantiene la room non è ancora esposto.
> **Preconditions:** Phase 1 DONE

## Fixed contracts for this phase

- Browser e server parlano il sottoprotocollo WebSocket esatto `bore-transfer-v1`; `Origin` e `Host` devono coincidere con l'origine/authority configurata.
- Close code privati: `4001` autenticazione, `4004` room non disponibile, `4008` rate/cap, `4010` versione. Il body applicativo usa i codici stabili documentati in Phase 0.
- Il primo messaggio controllo deve essere `hello` entro 10 secondi. Prima di esso il server non invia snapshot né dettagli sulla room.
- Il server assegna `peer_id` casuale a 128 bit e nome iniziale `Peer <ultime-4-cifre-hex>`. Il nome modificabile è normalizzato NFC, senza control character, trimmed, 1..48 caratteri Unicode.
- Disconnessione WebSocket peer: rimuove immediatamente peer, offerte e trasferimenti correlati. Lo stesso tab tenta la riconnessione e ripubblica dalle mappe `File` in memoria; non riprende download e non avvia trasferimenti.
- Eventi broadcast contengono soltanto ID e stato piccolo. Manifest e snapshot viaggiano come messaggi per-peer, una voce/offerta alla volta. Un receiver in lag riceve un nuovo snapshot; non si aumenta la capacità 256.
- Nessun elemento UI o codice di bootstrap può costruire `RTCPeerConnection`, aprire il relay, leggere un file per inviarlo o emettere `transfer.request` in questa fase.

### 2.2 Implement authenticated peer sessions, event delivery and snapshots

## Phase done criterion

Una room creata dall'harness accetta browser autenticati, presenta peer e offerte firmate, converge dopo lag/reconnect e rimuove subito lo stato di un peer disconnesso. T-WEB-NOAUTO dimostra che nessun payload o handshake parte senza click. Nessun comando pubblico è documentato, e `STATE.md` §11 mostra Phase 2 `DONE` con ogni subfase chiusa.
