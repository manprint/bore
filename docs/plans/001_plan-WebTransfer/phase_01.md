## Fixed contracts for this phase

- Put domain constants and pure validation in `src/web_transfer.rs`; put browser/native JSON and binary wire types in `src/web_transfer_protocol.rs`. Do not place browser state in `src/transfer.rs`.
- New `ClientMessage` and `ServerMessage` variants are deferred to Phase 1 and must be appended to their enums. This phase may define the payload structs independently.
- `web/transfer/dist` is generated, reviewed and committed. Cargo builds embed it and never invoke npm.
- Rust and JavaScript consume identical fixture files under `tests/fixtures/web_transfer/v1`; do not maintain two handwritten expected encodings.
- All public identifiers use lowercase fixed-width hexadecimal. Reject uppercase, prefixes, whitespace and wrong length.
- This phase introduces no route, server flag or CLI command.
