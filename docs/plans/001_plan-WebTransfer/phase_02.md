## Fixed contracts for this phase

- `WebTransferRegistry` is `Arc<DashMap<RoomId, Arc<WebTransferRoom>>>`. The map contains no await-held guard.
- Each `WebTransferRoom` owns a `std::sync::Mutex<RoomState>`, immutable limits, a `broadcast::Sender<RoomEvent>` of capacity 256, a cancellation token and monotonic `owner_epoch`.
- A `RoomState` contains only metadata: token hashes, owner lease state, peer/offer/transfer maps and counters. It must not contain file bytes, ciphertext, filesystem paths, `File` handles or unbounded queues.
- Room IDs are server-generated; secret tokens are client-generated. Collision retries are bounded and a failure returns `INTERNAL` without overwriting an existing room.
- Clean close destroys immediately. Native control EOF/dial failure detaches the owner and schedules expiry after the configured grace. Resume with the right token increments epoch and cancels the old expiry logically.
- A stale expiry task captures `Weak<WebTransferRoom>` plus its epoch and may remove the registry entry only with `DashMap::remove_if` when both pointer identity and epoch still match.
- Heartbeat send is bounded with `client::beat_once`; server receive liveness is checked from a 500 ms tick against `last_recv`, never through `timeout(recv)`.
